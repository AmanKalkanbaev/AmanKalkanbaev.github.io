# Портфолио Амана Калканбаева

Статичный сайт: открывается как есть, без сборки. Публикуется через GitHub Pages.

## Где что лежит

| Файл | Что это |
|---|---|
| `index.html` | Страница: заголовок, тексты, лента программ |
| `js/works.js` | Все работы и контакты. Чаще всего правится этот файл |
| `js/site.js` | Логика: плитки, просмотр работ, плееры |
| `css/site.css` | Оформление |
| `assets/` | Картинки, обложки, шрифты, логотипы программ |

## Как добавить работу

Все работы перечислены в `js/works.js`, по одной строке на работу.

- **Ролик с YouTube.** Строка в списке `motion`, в поле `yt` код из ссылки `youtu.be/КОД`. У видео должен быть доступ «по ссылке» или открытый и разрешено встраивание.
- **Рилс из Instagram.** Строка в списке `reels`, в поле `ig` код из ссылки, в `kind` слово `reel` или `p`, как в самой ссылке. Аккаунт должен быть открытым.
- **Картинка.** Строка в списке `graphics`.

Обложки и картинки для сайта готовит скрипт вне этой папки (`portfolio/build_assets.py`): он уменьшает исходники и кладёт их в `assets/`.

## Контакты

В начале `js/works.js` есть строка `contacts`. Заполненные поля появляются на сайте кнопками, пустые не показываются.

## Что стоит знать

- Рилсы играют через официальный встроенный плеер Instagram. Рамка плеера скрыта, остаётся только видео. Если Instagram поменяет вёрстку плеера, поправить нужно три числа в начале блока «Просмотр работы» в `js/site.js`.
- Некоторые рилсы Instagram не разрешает играть на других сайтах. У такой работы в `works.js` стоит `external: true`: вместо плеера показывается обложка и кнопка «Смотреть в Instagram».
- Логотипы программ принадлежат их владельцам и стоят здесь только как обозначение инструментов.
